# Skyline Technologies コーポレートサイト

## 概要

スカイライン・テクノロジーズ株式会社のコーポレートサイトです。
クラウド・AI・モバイルを軸としたソフトウェア開発会社として、サービス内容や導入実績、チームを紹介し、問い合わせへつなげることを目的としています。

1 ページの中を縦にスクロールして閲覧する構成で、次の内容を掲載しています。

| セクション | 内容 |
| --- | --- |
| ナビゲーション・お知らせ | 各セクションへのリンクと、最新のお知らせ（画面上部に固定） |
| トップ | キャッチコピー「未来を動かすテクノロジーを、共に。」と相談ボタン |
| 実績数値 | 導入企業数 200 社以上、顧客満足度 98% など |
| サービス | クラウド、AI / 機械学習、モバイルアプリ、セキュリティ、API 開発、データ基盤の 6 分野 |
| 導入実績 | FinTech・HealthTech・E-Commerce の事例 3 件 |
| チーム | 経営陣・リードメンバー 4 名の紹介 |
| お問い合わせ | 名前・メールアドレス・会社名・内容を入力するフォーム |

HTML・CSS・JavaScript はすべて `index.html` 1 ファイルにまとまっています。
ソフトのインストールやビルド作業は不要で、ブラウザだけで表示できます。

> **注意：** お問い合わせフォームは画面表示だけの仮実装です。送信ボタンを押すと完了表示になりますが、データはどこにも送信されません。

## ブラウザで index.html を開く手順

Google Chrome、Microsoft Edge、Firefox、Safari など、一般的なブラウザで表示できます。

### 方法 1：ダブルクリックで開く（Windows / Mac 共通）

1. エクスプローラー（Mac は Finder）で `skyline-technologies` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザが起動し、サイトが表示されます。

### 方法 2：ブラウザを指定して開く

使いたいブラウザが既定のブラウザではない場合の手順です。

- **Windows：** `index.html` を右クリック →「プログラムから開く」→ 使いたいブラウザを選択します。
- **Mac：** `index.html` を右クリック →「このアプリケーションで開く」→ 使いたいブラウザを選択します。

### 方法 3：ブラウザにドラッグ＆ドロップする

1. 先にブラウザを起動しておきます。
2. `index.html` をブラウザのウィンドウ（タブ部分やページ部分）へドラッグ＆ドロップします。

### 表示を更新するには

`index.html` を編集したあとは、ブラウザで **F5**（Mac は **⌘ + R**）を押すと最新の内容が反映されます。
反映されない場合は **Ctrl + F5**（Mac は **⌘ + Shift + R**）で再読み込みしてください。
